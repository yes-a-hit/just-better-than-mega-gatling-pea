# audio/

本目录存放大哥 BGM。

## 当前内容

`mega-gatling-bgm.ogg`——由本项目作者使用 **ACE-Step 1.5 XL Turbo** 本地生成的
8-bit 燃系战斗曲（BPM 148，60 秒，E minor，48000 Hz 立体声）。
来源与生成参数见仓库根的 [`NOTICE.md`](../NOTICE.md) 第 3 节。

## 想换一首？

把文件命名为 `mega-gatling-bgm.<扩展名>` 放进本目录即可，模组会自动识别：

| 扩展名 | 说明 |
|---|---|
| `.ogg` / `.oga` | 推荐，体积与兼容性最均衡 |
| `.mp3` | 常用格式，直接可用 |
| `.m4a` / `.wav` | 也支持，但体积偏大 |

多个文件同时存在时，按 `ogg → oga → mp3 → m4a → wav` 的顺序取第一个。
模组面板的「资源」行会显示实际生效的文件。

请使用自制、明确授权（CC0 / CC-BY 等）或公共领域的音频——
本仓库会公开分发这个目录。

## 制作建议

- 时长 60~100 秒足够（关卡循环播放），BPM 140~155 观感最好。
- 建议 44100 Hz 立体声，峰值 −1 ~ −3 dBFS：要压得过环境音、但不能盖掉音效。
- 开头不要长前奏：植物一落地模组就会接管 BGM，等 8 秒才进主题会很突兀。

## 没有音频时会发生什么

**不会出问题。** 模组会检测素材是否可用，读不到就完全不动引擎音乐，
关卡 BGM 照常播放——不会出现"静音了但没东西可播"的情况。

面板「资源」行会显示 `未找到 ...`，日志里也有对应记录。

## 关于 `private/`

仓库根目录另有 `private/`，**已被 `.gitignore` 排除、不会上传**，
用来放仅本地自用的素材。`tools/pack.ps1 -Personal` 会优先取那里的文件打包，
公版打包（不带参数）则完全忽略它。
